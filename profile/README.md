## About the name

Hypalyra draws its name from Hypatia—the mathematician, astronomer, philosopher, and teacher of Alexandria—and Lyra, the ancient constellation whose name is rooted in music, poetry, and expression. It evokes a place where language is not merely studied, but observed like a night sky: patterns emerge, meanings connect, and scattered fragments become constellations of understanding. 
Hypalyra represents the meeting of reason and imagination, where reading, mathematics, computational analysis, and memory work together to illuminate what was once hidden. It is a name for the quiet expansion of the mind through knowledge.
